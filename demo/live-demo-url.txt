MedSynapse AI Live Local Prototype:
The application runs as a complete, unified full-stack system serving both the FastAPI REST API and compiled React 18 production bundle on port 8000.

Run locally:
1. pip install -r requirements.txt
2. python -m uvicorn src.backend.main:app --host 0.0.0.0 --port 8000
3. Navigate to http://localhost:8000
